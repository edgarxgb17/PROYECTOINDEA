# Sprint 3 · Primer flujo funcional

Se incorpora el código de inicio de sesión, gestión de clientes y recepción de equipos para reparación. El flujo permite entrar al sistema, registrar al cliente y capturar el equipo y la falla para generar su folio.

Para revisarlo, ejecutar el SQL de instalación en una base nueva, copiar la configuración de ejemplo a `config/db.properties`, completar los datos locales e iniciar `com.indea.Main`. En Eclipse se requiere agregar MySQL Connector/J al proyecto.
