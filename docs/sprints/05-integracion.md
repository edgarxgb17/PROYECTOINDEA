# Sprint 5 · Integración de módulos

Se integran inventario, compras, ventas, empleados, publicaciones y reportes con el acceso y el seguimiento de reparaciones. La interfaz incorpora la consulta por folio y la navegación desde el panel principal.

El SQL de instalación añade la fecha de pago necesaria para los reportes de reparaciones y las cuentas de demostración de la aplicación. Los perfiles propios del servidor MySQL no forman parte de este incremento.
